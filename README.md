## Abstract

This report analyzes the public GitHub project Recommendation-System. The repository implements a medicine or health-product recommendation workflow using three complementary approaches: content-based filtering, user-based collaborative filtering, and truncated singular value decomposition (SVD) for rating prediction. The repository contains an executed Jupyter Notebook, an item catalogue named medicine_items.csv, a ratings file named medicine_ratings.csv, and a README file. The notebook loads 60 items and 1,500 ratings, constructs text representations from item descriptions, computes cosine similarity between products, forms a user-item rating matrix, generates user-based recommendations, and evaluates an SVD collaborative-filtering model on held-out ratings.

The content-based method uses TF-IDF on the item descriptions and recommends products with similar descriptions. For a Pain Relief seed item, the notebook reports high similarity scores for other Pain Relief products, including similarities of 0.788407, 0.782039, 0.649216, 0.629288, and 0.622150. The user-based method computes cosine similarity between users after filling missing ratings with zero, then calculates similarity-weighted ratings for items the target user has not rated. The SVD model is evaluated using an 80/20 random split and reports RMSE 1.095 on 300 held-out ratings, compared with 1.110 for the global-average baseline.

The project is a clear educational demonstration of a hybrid recommendation-system design. However, its results should not be interpreted as clinical advice or evidence of medical suitability. The catalogue appears synthetic or template-like, the dataset is small and sparse, and the evaluation uses one random split. The repository README is also inconsistent with the notebook: it contains an unrelated sentiment-analysis report. These limitations should be corrected before deployment or before claiming that the system provides safe, personalized medicine recommendations.

*Keywords:* recommendation system, content-based filtering, collaborative filtering, TF-IDF, cosine similarity, SVD, medicine products, rating prediction.
