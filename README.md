## Abstract

This report presents an analysis of the public GitHub project NLP_And_Sentiment_Analysis. The project applies classical natural language processing and supervised machine learning to online food reviews. Its objective is to classify each review into one of three sentiment categories: positive, neutral, or negative. The repository contains an executed Jupyter Notebook and a CSV dataset. The notebook loads 3,000 reviews, cleans the text with standard Natural Language Toolkit (NLTK) operations, converts the cleaned text into TF-IDF features using word unigrams and bigrams, and compares Logistic Regression, Multinomial Naive Bayes, and Linear Support Vector Machine models.

The notebook reports that all three models achieved 1.00 accuracy, precision, recall, and F1-score on a 600-review test set. Logistic Regression is selected as the best model, although the reported tie means that the selection is not meaningfully separated by the displayed metrics. The result demonstrates that the particular dataset is highly learnable using sparse lexical features. However, the perfect score should be interpreted carefully. The data contains repeated, template-like review patterns, and the notebook uses a single random train/test split rather than cross-validation or a duplicate-aware split. Therefore, the experiment is a useful educational demonstration of an NLP workflow, but it is not sufficient by itself to establish production-level generalization to unseen food platforms, products, writing styles, or real customer language.

*Keywords:* natural language processing, sentiment analysis, TF-IDF, Logistic Regression, Naive Bayes, Linear SVM, online food reviews, text classification.
